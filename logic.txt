---------------------------- LOGIC ------------------------------

1. device updates
2. the output pin changes
3. solve the net attached to it
4. if the resolved value != previous value -> update all input pins
5. collect each input devices
6. update each device
7. if output value of device changes -> return netid attached to the output pin
8. collect each net
9. solve net
10. continue solving network until delta becomes maxDelta
11. if it reaches limit then stop solving and mark value of the pin as X
